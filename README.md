### Featured work

**[cti-ioc-enrichment](https://github.com/FarfallaJ/cti-ioc-enrichment)** — a multi-source IOC enrichment & scoring engine. Give it an IP, domain, URL, or file hash and it fans out across **10 sources** (VirusTotal, OTX, AbuseIPDB, GreyNoise, Shodan, urlscan.io, abuse.ch, plus keyless crt.sh / RDAP / InternetDB), returns a transparent weighted verdict, and generates tactical briefs and **Sigma / YARA / Suricata** detections.
